Detailed Description

template<class Receiver>
class fyuu_rhi::execution::CommandGraphBindings< Receiver >

Move-only operation state containing a planned graph and its GPU objects.

Bind every registered slot exactly once, set presentation targets, then call start(). On success objects are delivered to set_value(); before an error or cancellation they are first returned through RecoverBindings(). Completion may run on an internal worker thread.
